保留它们的理由：

- **接口细节有参考价值**：例如 `q.qlogo.cn` 的 `spec` 尺寸表、无效账号返回 971 字节占位图、`edge-tts 7.2.x` 的 403 原因（微软把 `SEC_MS_GEC_VERSION` 从 `1-` 改成 `2-`，且用改过初始状态的 SHA256）。
- **能解释代码里为什么这么写**：比如「只接受数字 QQ 号」是为了从根上排除 SSRF。
