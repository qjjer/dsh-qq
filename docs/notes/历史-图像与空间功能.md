## 新增：4 个头像相关 MCP 工具

| 工具 | 作用 | 默认 | 范围 |
|---|---|---|---|
| `qq_get_avatar` | 看某人的头像，进入视觉上下文 | **开** | 群聊/私聊都能用 |
| `qq_get_avatars` | 一次看多个（最多 20），用于认人 | **开** | 群聊/私聊都能用 |
| `qq_send_avatar` | 把某人头像当图片发到聊天 | **开** | 群聊/私聊都能用 |
| `qq_set_avatar` | 改机器人自己的头像（**不可逆**） | **关** | 仅管理员私聊 |

## 接口来源
`https://q.qlogo.cn/headimg_dl?dst_uin=<QQ号>&spec=<尺寸>&img_type=jpg`
- 免费、无需鉴权、只认数字 QQ 号
- spec：0=原图 / 1=40px / 3=100px / 4=140px / 5 或 640=640px
- 无效账号返回一张非 JPEG 的默认图（约 971 字节），代码据此判定"没有头像"

## 代码位置
- `src/bridge.js`：三个端点
  - `POST /api/socialV2/avatar` — 取头像（支持 `uin` 单个或 `uins` 数组）
  - `POST /api/socialV2/send-avatar` — 发头像到聊天
  - `POST /api/socialV2/set-avatar` — 改自己头像（读 `avatar/` 目录）
- `src/mcp-snowluma-safe.js`：4 个工具 + `TOOL_CONFIG_FLAGS` 登记
- `config.json` → `socialV2.tools`：seeAvatar / sendAvatar / setAvatar

## 安全设计
1. **只接受数字 QQ 号**，不接受 URL —— 从根上排除 SSRF，无需额外校验
2. **下载走 safeFetchBuffer**（项目既有的 SSRF 防护 + 大小上限）
3. **改头像限制在 `avatar/` 目录**，用 `path.basename` + `startsWith` 双重校验防路径穿越
4. **改头像默认关闭**（`setAvatar: false`），且仅管理员私聊；开启方法：把 `config.json` 里 `socialV2.tools.setAvatar` 改成 `true` 再重启 DSH
5. 批量看头像上限 20 个，单张上限 4 MB
