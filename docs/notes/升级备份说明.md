## 依赖要求
- **edge-tts >= 7.3.0**（Python）。旧版（7.2.x 及更早）会一直 403：
  微软把 DRM 换了，`SEC_MS_GEC_VERSION` 从 `1-` 变 `2-`，
  且 Sec-MS-GEC 用**改过初始状态**的 SHA256（不再是标准 SHA256）。
  升级命令：`python -m pip install --upgrade edge-tts`
- ffmpeg / ffprobe（探测时长用，可选）

## config.json
- `socialV2.tools` 新增：qzone / qzoneRead / qzonePost / qzoneLike / qzoneComment /
  setSignature / setOnlineStatus / setInputStatus（均 true）
- `socialV2.voice` 开启：enabled=true, tts=true, ttsVoice=zh-CN-XiaoxiaoNeural
- `socialV2.tools.sendVoice` = true
- 新增 `socialV2.qzone` 配额段（maxPostsPerDay=3 等）

## src/tts-cloud.js（新增文件）
Edge TTS 封装：synthesizeToLibrary / probeDuration / listChineseVoices

- 启动前校验版本 >= 7.3，低于就明确报错提示升级
- 产物写入 audio/（socialV2.voice.dir）

## 已知限制
- NapCat 没有删除空间评论的接口（只有 delete_qzone_public_comment，那是公共流）。
  评论一旦发出只能手机端手删。
- NapCat 没有 get_self_longnick，读自己签名借 get_stranger_info。
- DSH 沙箱会话内无法验证 TTS 合成（spawnSync 被拦 EPERM），需在普通终端验证。
